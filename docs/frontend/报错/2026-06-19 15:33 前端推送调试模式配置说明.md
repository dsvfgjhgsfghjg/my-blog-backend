# 前端推送调试模式配置说明

> **日期:** 2026-06-19  
> **关联文档:** [VUE3_PUSH_CHALLENGE_GUIDE.md](../../api/VUE3_PUSH_CHALLENGE_GUIDE.md)  
> **涉及页面:** `SystemSettings.vue`（系统配置）、`AppPushTest.vue`（推送测试）

---

## 背景

三选一挑战（Push Challenge）的调试模式由**后端系统配置** `security.app_auth.push_challenge_show_correct` 控制，而不是前端本地开关。

- **调试模式**（配置为 `true`）：API 只返回 `{deviceId, correctNumber, status}`，前端只显示一个绿色高亮的正确数字
- **正常模式**（配置为 `false`，默认）：API 返回 `{deviceId, challengeId, numbers, expiresAt, status}`，前端显示 3 个候选数字

## 需要前端做的修改

### 1. 在 SystemSettings.vue 中添加开关

后端已在 `t_system_config` 表中新增了配置项：

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `security.app_auth.push_challenge_show_correct` | BOOLEAN | `false` | 推送挑战时显示正确答案（调试用，生产环境应关闭） |

该配置属于 `SECURITY` 分类，`is_editable = true`，前端系统配置页面会自动加载。

**但是**，由于 `SystemSettings.vue` 中安全配置的"其他安全配置"区域使用了 `getOtherSecurityConfigs()` 过滤器（第96-103行），该过滤器排除了所有以 `security.login.`、`security.password.` 开头以及 `security.token.expiration` 和 `security.totp.` 开头的配置项。

`security.app_auth.push_challenge_show_correct` 以 `security.app_auth.` 开头，**不会被排除**，所以它会自动出现在"其他安全配置"的表格中，以 el-switch 开关形式展示（因为 configType 是 BOOLEAN）。

**无需修改 SystemSettings.vue 代码**，配置会自动显示在「安全配置 → 其他安全配置」表格中。

### 2. 在 AppPushTest.vue 中添加提示

建议在推送结果区域添加一个提示，告知用户当前处于什么模式：

```vue
<!-- 在推送操作区域添加提示 -->
<el-alert
  v-if="pushResults && pushResults.results.length > 0 && pushResults.results[0].correctNumber !== undefined"
  title="调试模式"
  type="warning"
  :closable="false"
  show-icon
  style="margin-bottom: 16px"
>
  <template #default>
    当前为调试模式，仅显示正确答案。如需显示 3 个候选数字，请在「系统设置 → 安全配置」中关闭「推送挑战时显示正确答案」。
  </template>
</el-alert>
```

### 3. 前端已实现的逻辑（无需修改）

`AppPushTest.vue` 中第541-565行已经实现了正确的判断逻辑：

```vue
<!-- 调试模式：只显示正确答案（correctNumber 存在时） -->
<template v-if="result.correctNumber !== undefined">
  <p class="numbers-label">推送的数字（调试模式）：</p>
  <div class="number-badges">
    <el-tag size="large" type="success" class="number-tag correct-number">
      {{ result.correctNumber }}
    </el-tag>
  </div>
  <p class="debug-hint">🛠️ 调试模式：这是正确答案</p>
</template>
<!-- 正常模式：显示 3 个候选数字 -->
<template v-else-if="result.numbers">
  <p class="numbers-label">推送的数字：</p>
  <div class="number-badges">
    <el-tag v-for="(num, index) in result.numbers" :key="index"
            size="large" type="info" class="number-tag">
      {{ num }}
    </el-tag>
  </div>
  <p class="numbers-hint">App 用户需要从这 3 个数字中选择正确的一个</p>
</template>
```

## 操作步骤

1. 登录管理后台
2. 进入「系统设置 → 安全配置」
3. 在「其他安全配置」表格中找到「推送挑战时显示正确答案（调试用，生产环境应关闭）」
4. 将开关切换为「启用」
5. 点击「保存配置」（需要 TOTP 验证）
6. 进入「推送测试」页面，点击推送，此时只显示正确数字

## 注意事项

- 调试模式仅供开发调试使用，**生产环境必须关闭**
- 修改配置后，下一次推送才会生效，已推送的挑战不受影响
- 该配置项在数据库中的默认值为 `false`（正常模式）
