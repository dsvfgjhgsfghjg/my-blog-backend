# 页面管理-关于我页面报错--无法保存博主信息

## 问题描述

2026-05-31 21:40，页面管理-关于我页面无法保存博主信息。当管理员尝试更新博主信息时，接口报错，保存失败。

## 根因分析

### 问题定位

后端存在**两个耦合的安全配置问题**，共同导致 `PUT /api/blogger/info` 接口无法被正确认证：

#### 问题1：JwtAuthenticationFilter 将写接口错误标记为公开路径

`JwtAuthenticationFilter.java` 中的 `PUBLIC_PATHS` 包含：
```java
"/api/blogger/info",   // ① 错误：将 GET/PUT/DELETE 全部标记为公开
"/api/blogger/avatar", // ② 错误：会匹配到 /api/blogger/avatar/upload
```

`shouldNotFilter()` 方法使用 `path.startsWith(publicPath)` 进行前缀匹配：
- `PUT /api/blogger/info` → 命中 `/api/blogger/info` → **跳过 JWT 过滤器**
- `POST /api/blogger/avatar/upload` → 命中 `/api/blogger/avatar` → **跳过 JWT 过滤器**

#### 问题2：SecurityConfig 未区分 HTTP 方法

```java
.requestMatchers("/api/blogger/info").permitAll()   // 所有方法都开放
.requestMatchers("/api/blogger/avatar").permitAll() // 所有方法都开放
```

`permitAll()` 默认对所有 HTTP 方法（GET、PUT、POST、DELETE 等）生效。

### 执行流程导致的问题

当管理员从「关于我」页面提交保存时：

1. 前端发送 `PUT /api/blogger/info`（携带 JWT Token）
2. `JwtAuthenticationFilter.shouldNotFilter()` → `path.startsWith("/api/blogger/info")` 为 true → **跳过过滤器**
3. Token 未被解析，`request.setAttribute("userId", ...)` **从未执行**
4. 请求到达 `BloggerInfoController.updateBloggerInfo()`
5. `AdminAspect.checkAdminPermission()` 尝试获取 `request.getAttribute("userId")` → **得到 null**
6. 抛出 `BusinessException("未认证或Token无效")`
7. 前端收到 500 错误，保存失败

## 修复方案

### 修改1：JwtAuthenticationFilter.java

从 `PUBLIC_PATHS` 中移除 `/api/blogger/info` 和 `/api/blogger/avatar`：

```java
// 移除前：
private static final String[] PUBLIC_PATHS = {
    ...
    "/api/blogger/info",
    "/api/blogger/avatar",
    ...
};

// 移除后：
private static final String[] PUBLIC_PATHS = {
    ...
    // 已移除 /api/blogger/info（PUT需要认证）
    // 已移除 /api/blogger/avatar（POST上传需要认证）
    ...
};
```

### 修改2：SecurityConfig.java

将 `permitAll()` 限制为仅 GET 方法：

```java
// 修改前：
.requestMatchers("/api/blogger/info").permitAll()
.requestMatchers("/api/blogger/avatar").permitAll()

// 修改后：
.requestMatchers(HttpMethod.GET, "/api/blogger/info").permitAll()
.requestMatchers(HttpMethod.GET, "/api/blogger/avatar").permitAll()
```

## 影响范围

- ✅ `GET /api/blogger/info` → 公开访问（正常）
- ✅ `PUT /api/blogger/info` → 需要JWT认证 + 管理员权限（修复后正常）
- ✅ `GET /api/blogger/avatar` → 公开访问（正常）
- ✅ `POST /api/blogger/avatar/upload` → 需要JWT认证 + 管理员权限（修复后正常）
